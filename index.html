Propuesta de desarrollo

Sistema de Gestión de Matrículas

Plataforma web para centralizar el proceso de matrícula de un colegio: preinscripción, documentos, validaciones, pagos y registro académico.

Aplicación Web SPA .NET Core / C# Java SQL Server Azure Service Bus
Presentación basada en los modelos C1, C2 y C3 del sistema.
01 · Propósito

¿Qué queremos solucionar?

📝

Proceso de matrícula

Digitalizar y centralizar las actividades que hacen parte del proceso de admisión y matrícula.

👤

Para los usuarios

Facilitar al estudiante y al administrador académico el acceso y seguimiento de la información.

🔗

Integración

Conectar el sistema central con pagos, notificaciones y sistemas institucionales.

🎯

Fin del proyecto

Contar con una solución organizada que permita gestionar la matrícula de principio a fin.

Idea principal: llevar el proceso de matrícula a una plataforma centralizada y conectada con los servicios necesarios.
02 · Modelo C1

¿Quiénes participan?

👤 Estudiante / Aspirante

Preinscripción, carga de documentos y pago en línea.


👤 Administrador Académico

Validación de requisitos, gestión de cupos y reportes.

Sistema central: Académica — plataforma central de admisiones, liquidación y registro académico.
03 · Modelo C2

¿Cómo está construido el sistema?

Capa de Presentación
Aplicación Web SPA con HTML, CSS y Bootstrap.
Capa de Negocio
Servicios Académicos en Java y Backend API en .NET Core / C#.
Capa de Persistencia
Base de datos relacional Microsoft SQL Server.
Capa de Asincronía
Azure Service Bus / Queue para mensajería asíncrona.
04 · Tecnologías

¿Para qué sirve cada herramienta?

🌐 HTML / CSS

Construyen la estructura y el diseño de la aplicación web.

📱 Bootstrap

Ayuda a crear una interfaz organizada y adaptable.

⚙️ .NET Core / C#

Implementa el Backend API principal y coordina operaciones.

☕ Java

Procesa validaciones y reglas de negocio de los servicios académicos.

🗄️ SQL Server

Almacena la información del sistema en una base de datos relacional.

☁️ Azure Service Bus

Maneja mensajes y procesos de forma asíncrona.
